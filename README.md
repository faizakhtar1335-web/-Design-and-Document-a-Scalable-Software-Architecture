# E-Commerce Microservices Architecture

Week 1 architecture assignment implementation.

## Features

- User registration
- Product catalog
- Shopping cart
- Order creation
- Payment simulation
- API Gateway
- Interactive CLI
- Optional FastAPI API

## Run CLI

```bash
python ecommerce_microservices.py
```

## Optional API

Install:

```bash
pip install fastapi uvicorn
```

Run:

```bash
uvicorn ecommerce_microservices:app --reload
```

Open:

```text
http://127.0.0.1:8000/docs
```

## GitHub

```bash
git init
git add .
git commit -m "Add e-commerce microservices Python implementation"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

## Important

This is an educational prototype. It uses in-memory data and simulates payment processing. A production system should use a real database, secure authentication, password hashing, Redis, Kafka, a compliant payment provider, secrets management, logging, monitoring, tests, Docker, and deployment infrastructure.
